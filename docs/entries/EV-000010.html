EV-000010

Max/min distance ratio, 16 points in the plane (squared) · Point configurations · status current

Definition

Minimum over 16 points in R^2 of (max pairwise distance / min pairwise distance)^2.

\min_{P\subset\mathbb R^2,|P|=16}\left(\frac{\max d}{\min d}\right)^2

Domain: 16-point sets in R^2. Normalisation: squared ratio (some sources state the unsquared ratio). Direction: min.
