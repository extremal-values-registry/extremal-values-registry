Third autocorrelation constant, signed f, maximum of the absolute value · Autocorrelation inequalities · status current

Definition

C = the largest constant with max_t |(f*f)(t)| >= C (int f)^2 for every real f supported on [-1/4,1/4]. Any explicit f gives the upper bound C <= max_t |(f*f)(t)| / (int f)^2. Entries record the best upper bound.

C=\inf_{f:\ \operatorname{supp}f\subseteq[-\frac14,\frac14],\ \int f\ne0}\frac{\max_t\left|(f*f)(t)\right|}{(\int f)^2}

Domain: real-valued functions on [-1/4,1/4]. Normalisation: dimensionless ratio. Direction: min.
